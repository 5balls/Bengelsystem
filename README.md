# Bengelsystem
Bengelsystem is a platform to schedule shifts of volunteers primarily for jugglig conventions. Helpers are registered at the platform (either themselves or transparently via an invite link) and then choose shifts to fill - often after pre-communicated agreements. The admin of the website can add new tasks and shifts.

Das Bengelsystem ist Datenbanksystem, um Hilfsdienste - primär auf Jonglierconventions zu organiseren. Nach Accounterstellung (transparent über einen Link mit Accountdaten möglich) wählen Leute ihre Schichten aus - oft nach vorher ausgemachten Abmachungen.  Ein Admin auf den Seiten kann neue Dienste und Schichten anlegen etc.
